F04 — What is an inverter? (why 6 switches)

A motor drive does not directly “output smooth sine waves”. It uses a power stage called an inverter, built from fast ON/OFF electronic switches.

On this page 1) 10-second definition 2) The power path (DC → inverter → motor) 3) Why 6 switches? 4) The key limitation: only a few instant states Next

1) 10-second definition

Inverter (motor drive):
The inverter takes DC electricity (battery / DC bus) and creates controlled three-phase electricity for the motor by switching transistors ON and OFF very fast.

2) The power path (DC → inverter → motor)

DC source (battery / DC bus) → inverter → motor phases (A, B, C)

The motor has three phase wires (A, B, C). The inverter is a “smart switchbox” that connects each phase either to +DC or to −DC.

3) Why 6 switches?

Each motor phase must sometimes be connected to +DC and sometimes to −DC. So each phase uses two switches:

One phase leg:
– Top switch connects phase to +DC
– Bottom switch connects phase to −DC
3 phases × 2 switches = 6 switches

Safety note: Top and bottom switch of the same phase must never be ON at the same time (shoot-through). Real inverters add a small gap called dead-time.

4) The key limitation: only a few instant states

Because each switch is only ON or OFF, the inverter can only produce a limited set of instant voltage states. It cannot output “any voltage you want” instantly.

This limitation is why we use PWM: PWM turns ON/OFF switching into a controllable average voltage.

Later, SVM is the clean geometric version of PWM for 3-phase systems: SVM 01.
